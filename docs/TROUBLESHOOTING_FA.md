# عیب‌یابی فارسی

## سرویس Client فعال است ولی کانفیگ تایم‌اوت می‌دهد

به‌ترتیب این موارد را بررسی کنید:

1. خروجی `sudo backhaul-manager doctor` روی سرور ایران.
2. وجود پیام `control channel established successfully` در لاگ Client.
3. بازبودن پورت کنترل و پورت‌های عمومی در فایروال و پنل دیتاسنتر.
4. اشاره رکورد A دامنه کشور به IP همان سرور ایران.
5. نبودن رکورد AAAA اشتباه.
6. یکسان‌بودن Port کانفیگ کاربر با پورت سمت چپ `--map`.
7. یکسان‌بودن SNI کانفیگ کاربر با دامنه گواهی TLS اینباند Xray.
8. فعال‌بودن پورت مقصد Xray روی سرور خارج.

## کانال کنترل برقرار نمی‌شود

روی Client:

```bash
sudo backhaul-manager logs client COUNTRY_NAME
```

خطاهای رایج:

- `connection refused`: پورت کنترل روی ایران گوش نمی‌دهد یا سرویس Server خاموش است.
- `i/o timeout`: فایروال، Route یا دیتاسنتر مسیر را می‌بندد.
- خطای Token: توکن Server و Client یکسان نیست.

## فقط یکی از سه پورت کار نمی‌کند

نگاشت همان پورت و Listener محلی Xray را بررسی کنید:

```bash
ss -lntp | grep -E ':(8090|8091|8092)[[:space:]]'
```

## Rollback باینری

دستور `binary install` پیش از جایگزینی باینری، نسخه قبلی را با پسوند
`.bak.YYYYMMDD_HHMMSS` نگه می‌دارد. اگر سرویس‌ها بعد از Update فعال نشوند، Rollback
خودکار انجام می‌شود.


## Update به علت نبود Digest متوقف می‌شود

این توقف یک کنترل امنیتی است. ابتدا مطمئن شوید ساعت سرور، DNS و دسترسی به
`api.github.com` و `github.com` درست است. برای آخرین نسخه رسمی دوباره اجرا کنید:

```bash
sudo homa binary install --latest
```

گزینه `--allow-unverified-download` فقط یک عبور صریح از کنترل Hash است و برای
استفاده عادی توصیه نمی‌شود.

## Restore بکاپ شکست می‌خورد

- آرشیو باید مستقیماً داخل `/var/backups/backhaul-manager` باشد.
- آرشیوهای دارای Symlink، مسیر `../`، مسیر مطلق، فایل تکراری یا فایل ناشناخته رد می‌شوند.
- هنگام Restore یک Safety Backup جدید ساخته می‌شود؛ مسیر آن در پیام خطا نمایش داده می‌شود.
- اگر سرویس بازیابی‌شده پایدار نماند، فایل‌ها و وضعیت قبلی Rollback می‌شوند.

## منو در گوشی ناقص یا شکسته دیده می‌شود

نسخه 1.1.10 در ترمینال‌های باریک، لوگوی کامل پنج‌خطی HOMA را تا زمانی که حداقل
۲۰ ردیف وجود داشته باشد نگه می‌دارد و متن گزینه‌ها را پیش از Wrap کوتاه می‌کند.
فقط در ارتفاع کمتر از ۲۰ ردیف، نشان فشرده `[ HOMA ]` نمایش داده می‌شود تا منو وارد
Scrollback نشود. در Termius یا MobaXterm اندازه Font را طوری تنظیم کنید که حداقل
۲۰ ستون در دسترس باشد. اگر ابعاد ترمینال اشتباه تشخیص داده می‌شود، اتصال SSH را
یک بار باز و بسته کنید تا مقدار Rows/Columns تازه شود.
## پرپرزدن منو یا دیده‌شدن صفحه‌های قبلی در Termius

از نسخه 1.1.11 انتخاب با کلیدهای جهت به‌صورت افزایشی رندر می‌شود و فقط دو خط
تغییر می‌کنند. همچنین خروجی وضعیت، Health Check و بکاپ پس از Enter درجا پاک
می‌شود و نباید بالای منوی جدید باقی بماند. تاریخچه قبل از اجرای `bh` عمداً حفظ
می‌شود.
